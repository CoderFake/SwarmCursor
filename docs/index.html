2. <SwarmProvider> & <SwarmElement> DOM-Driven Mode

Bọc trang React của bạn bằng <SwarmProvider> và đánh dấu các phần tử cần được đàn chuột AI vẽ bằng <SwarmElement>. Hỗ trợ cả 3 chế độ cuộn: "manual" (kéo tới đâu vẽ tới đó), "auto" (tự động cuộn), và "hybrid".

PortfolioPage.tsx 
import { SwarmProvider, SwarmElement, SwarmControls } from "swarm-cursor/react";
import "swarm-cursor/styles.css";

export default function PortfolioPage() {
  return (
    <SwarmProvider
      scrollMode="hybrid"
      autoScrollSpeed={180}
      showCursorLabels={true}
      agentPill={{ maxIcons: 5, intervalMs: 650 }} // Chỉ hiện khi khai báo
    >
      <SwarmElement id="hero-title" tool="text" grow snapAxis="x">
        <h1>Creative Developer Portfolio</h1>
      </SwarmElement>

      <SwarmElement id="project-1" tool="rect" deps={["hero-title"]} snapAxis="y">
        <div className="card">Dự án được chuột AI vẽ khung & đổ màu</div>
      </SwarmElement>

      <SwarmControls position="bottom-right" />
    </SwarmProvider>
  );
}

3. <SwarmFollower> Follow & Circular Orbit

Component độc lập giúp đàn chuột đuổi theo chuột người dùng khi di chuyển và xoay vòng tròn (Vortex Orbit) quanh mũi chuột khi chuột dừng lại. Thanh pill ở đáy màn hình mặc định tắt trừ khi bạn khai báo prop agentPill.

CursorOverlay.tsx 
import { SwarmFollower } from "swarm-cursor/react";
import "swarm-cursor/styles.css";

export function CursorOverlay() {
  return (
    <SwarmFollower
      count={30}
      radiusScale={1}
      tempoMultiplier={1}
      showLabels={false}
      agentPill={true} // Khai báo mới hiện thanh 5 icon + "30 agents"
    />
  );
}

4. <SwarmAgentPill> Opt-in · Max 5 Icons Queue · {N} agents

Thanh trạng thái kiểu Figma ở bottom bar: hiển thị tối đa 5 icon tròn xếp chồng lấy ngẫu nhiên từ 9 bộ icon AI (claude, cohere, deepseek, gemini, grok, kimi, mistral, ollama, openai). Các icon nhảy ngẫu nhiên liên tục đẩy từ trái qua phải giống hàng đợi (queue) các agent đang làm việc, kèm nhãn {N} agents.

BottomAgentQueue.tsx 
import { SwarmAgentPill } from "swarm-cursor/react";
import "swarm-cursor/styles.css";

export function BottomAgentQueue() {
  return (
    <SwarmAgentPill
      count={30}
      maxIcons={5}               // Tối đa 5 icon (hard-capped <= 5)
      intervalMs={650}           // Chu kỳ đẩy queue từ trái sang phải (ms)
      position="bottom-center"   // "bottom-center" | "bottom-left" | "bottom-right" | "inline"
      icons={["claude", "openai", "gemini", "deepseek", "grok", "kimi", "mistral"]}
    />
  );
}
Prop Kiểu dữ liệu Mặc định Mô tả
count number engine?.cursors.length ?? 36 Số lượng hiển thị trong {N} agents.
maxIcons number 5 Số lượng icon tối đa hiển thị cùng lúc (luôn khóa ở mức ≤ 5).
intervalMs number 650 Thời gian (ms) mỗi nhịp đẩy 1 icon AI ngẫu nhiên mới từ trái qua phải.
icons AgentIconId[] Tất cả 9 icon AI Danh sách lọc các icon được phép xuất hiện.
position "bottom-center" | "bottom-left" | "bottom-right" | "inline" "bottom-center" Vị trí cố định dưới bottom bar hoặc inline.
label string | ((count: number) => string) (n) => `${n} agents` Tùy biến chuỗi hiển thị bên phải hàng đợi icon.

5. <SwarmCanvas> & SceneBuilder Virtual Artboard

CustomArtboard.tsx 
import { SceneBuilder } from "swarm-cursor";
import { SwarmCanvas } from "swarm-cursor/react";
import "swarm-cursor/styles.css";

const customScene = () => {
  const b = new SceneBuilder(1280);
  const gLeft = b.guideX(80, 100);
  const title = b.text(80, 140, "SwarmCursor Artboard", "h1", {
    w: 620,
    grow: true,
    deps: [gLeft],
  });
  const card = b.rect(80, 280, 340, 180, {
    fill: "#FFFFFF",
    stroke: "#E2E4E9",
    r: 14,
    deps: [title],
  });
  b.dupGroup("row", [card], [{ dx: 370, dy: 0 }, { dx: 740, dy: 0 }], [card]);
  return b.build(600);
};

export default function CustomArtboard() {
  return <SwarmCanvas scene={customScene} scrollMode="hybrid" controls agentPill />;
}

6. <SwarmControls> & useSwarm() Hook

CustomToolbar.tsx 
import { useSwarm } from "swarm-cursor/react";

export function CustomToolbar() {
  const { engine, start, pause, resume, reset, setScrollMode } = useSwarm();
  return (
    <div className="toolbar">
      <button onClick={() => (engine.paused ? resume() : pause())}>
        {engine.paused ? "Resume" : "Pause"}
      </button>
      <button onClick={reset}>Reset</button>
      <button onClick={() => setScrollMode("auto")}>Auto Scroll</button>
    </div>
  );
}

7. Vanilla JS / TypeScript API

vanilla-example.ts 
import {
  createSwarm,
  createSwarmFollower,
  createSwarmAgentPill,
} from "swarm-cursor";
import "swarm-cursor/styles.css";

// 1. Quét DOM [data-swarm] và cho chuột vẽ khi kéo trang
const swarm = createSwarm({
  container: document.body,
  mode: "dom",
  scrollMode: "hybrid",
  agentPill: { maxIcons: 5, intervalMs: 650 }, // Chỉ hiện khi khai báo
});

// 2. Hoặc chỉ chạy đàn chuột đuổi & xoay vòng quanh trỏ chuột
const follower = createSwarmFollower({
  count: 30,
  radiusScale: 1,
  agentPill: true,
});

// 3. Hoặc gọi riêng thanh Bottom-Bar Queue 5 Icon AI
const pill = createSwarmAgentPill({
  count: 30,
  maxIcons: 5,
  intervalMs: 650,
});

8. Bảng thuộc tính data-swarm-* & CSS Variables

Thuộc tính HTML Giá trị Mô tả
data-swarm "rect" | "text" | "path" Công cụ Figma mà chuột AI sẽ dùng để vẽ phần tử.
data-swarm-id string ID định danh phần tử để liên kết phụ thuộc (deps).
data-swarm-deps "id1,id2" Danh sách các ID phải hoàn thành trước khi vẽ phần tử này.
data-swarm-grow "true" Gõ chữ cỡ nhỏ trước rồi bôi đen phóng to cỡ chữ.
data-swarm-snap "x" | "y" | "xy" Kéo thước căn lề đỏ từ Ruler trên/trái khớp vào cạnh phần tử.
